# 拜耳时光片图片生成平台

这是可继续开发和发布的完整离线源代码包。

## 直接预览

打开 `index.html`。图片资源位于 `public/`，必须与 `index.html` 保持同级目录关系。

## 继续开发

- 当前平台为原生 HTML、CSS、JavaScript 单页应用，不需要安装依赖。
- 主源代码就是 `index.html`；`source/素材库_可编辑版_20260818_v9.html` 是同一版本的备份。
- 修改后用浏览器打开 `index.html` 检查效果。
- 发布到 GitHub Pages 时，将 `index.html` 和整个 `public/` 上传到仓库根目录。
- GitHub Pages 使用 `main` 分支和 `/ (root)` 目录。

## 当前功能

- 左侧平台导航：素材库、产品建模、提示词、图片生成。
- 素材库分类、手动编辑、删除和恢复。
- 时光片产品建模图片展示。
- 批量选择参考素材并生成多条高差异 GPT 图片提示词。
- 自动产品参考说明、文字道具库和批次差异设计。

## 尚未完成

- 接入视觉模型，对每张参考图实际分析构图、光线、色调和具体道具。
- 接入 OpenAI 图片生成 API。
- 图片生成任务状态、结果预览、筛选和重新生成。
- 后端安全保存 API Key；不要把 API Key 直接写入 `index.html`。

## 关键规则

- 参考图只用于学习分类感觉、色调家族、光线质感和居家摄影氛围，不直接复刻。
- 同一参考图的批量结果必须在机位、产品位置、家具、道具和光线关系上具有明显差异。
- 用户只选择“时光片”，系统自动附加完整产品建模参考。
- 只出现居家环境；不出现完整人物、户外或浴室；只允许自然手部或手臂。
- 产品包装、文字、品牌、结构、药板和药片比例必须保持一致。
